# Bosses opcionais

Existem **exatamente quatro** no canon atual. São criaturas extraordinárias, lendárias ou livremente inspiradas em mitologia/folclore, sem relação direta com os mortos da história principal. Podem existir naturalmente no mundo. Nenhuma é obrigatória para terminar a campanha.

Cada boss concede uma melhoria permanente importante, sem níveis. A recompensa possui uma única fonte: a nota individual.
