# Controles — fonte principal

DualSense/PS5 é a referência primária de design; outros controles e teclado/mouse serão adaptados posteriormente. Esta tabela descreve o novo design, não o Input Map já implementado.

| Entrada | Função |
|---|---|
| Analógico esquerdo | Movimento |
| Quadrado | Katana rápida |
| Triângulo | Katana pesada |
| Círculo | Dash/rolamento |
| X | Interagir com NPC, cenário, objeto ou mecanismo |
| L1 + D-Pad | Selecionar uma das quatro magias |
| R1 | Usar magia selecionada |
| Segurar L2 | Mira/trava do arco |
| Analógico direito durante mira | Alternar alvo |
| R2 | Disparar arco |
| Soltar L2 | Encerrar mira |
| Touchpad | **proposal:** candidato ao mapa completo |
| L3 / R3 | Sem função obrigatória |

**needs-decision:** confirmação do Touchpad, menus/pausa, remapeamento, equivalentes de teclado/mouse e outros controles. Posições sugeridas da seleção: [[50_Arte_Audio_UI/UI_HUD]]. Teste físico do controle não executado nesta tarefa.
