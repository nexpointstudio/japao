# Pesquisa não é canon

Aqui ficam referências e futuras verificações culturais. [[Pesquisa/Referencias_Culturais]] lista nomes fornecidos pelo usuário; não comprova fatos históricos.

O canon de design fica nos domínios 02/10/20/30/40/50. Pesquisa só informa adaptações originais após decisão explícita. Não apresentar criação ficcional como prática religiosa ou mito real. Não importar a pesquisa antiga como validação de novos personagens.
